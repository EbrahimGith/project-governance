# Norouz Club Project Governance

**Version 1.0 — Draft for team review**

## Purpose
A simple, shared GitHub process for Norouz Club projects, from HTML pages to open-source applications.

## Core rules
- All official repositories belong to the Norouz Club organization.
- Each independent project has its own repository and a responsible maintainer.
- In version 1.0, **everyone contributes through a personal fork and a pull request**, including maintainers when contributing changes.
- No direct pushes to protected upstream branches.
- At least one independent, authorized reviewer must approve each PR before an authorized maintainer merges it.
- Each project defines its own branching strategy. Start with `main`; add other branches only when needed.
- Deployment is optional and project-specific.

## Project lifecycle
Proposal → Team approval → Repository setup → Issues → Fork and PR → Review → Merge → Release (if needed)

## Updating this policy
Open an issue or submit a PR to this governance repository. The team reviews and agrees on changes before adopting a new version.

## Project templates
Copy the relevant files from [templates](templates/README.md) into each new repository. Every project must have an `ONBOARDING.md`.
