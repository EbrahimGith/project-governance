# Project templates
Copy files into the new project repository; replace all placeholders.

| Template | Destination | Required |
|---|---|---|
| [ONBOARDING.md](ONBOARDING.md) | `ONBOARDING.md` | Yes |
| [BRANCHING_STRATEGY.md](BRANCHING_STRATEGY.md) | `docs/BRANCHING_STRATEGY.md` | Yes |
| [PROJECT_PROPOSAL.md](PROJECT_PROPOSAL.md) | New issue in governance repository | For new projects |
| [ISSUE_TEMPLATE.md](ISSUE_TEMPLATE.md) | `.github/ISSUE_TEMPLATE/work.md` | Recommended |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | `.github/PULL_REQUEST_TEMPLATE.md` | Recommended |

Link onboarding and branching strategy from the project README. Templates are copied manually; this folder is not an automatic GitHub template repository.
